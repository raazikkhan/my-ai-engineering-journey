🚀 6-Month Program

AI Engineer
Roadmap

From zero to job-ready. A structured, week-by-week path to becoming a modern AI engineer.

Month 01

Foundations

4 WEEKS
🧱
Goal: Build unshakeable fundamentals. No shortcuts — this is the bedrock everything else rests on. Focus on understanding, not just running code.
Week 01
Python Mastery
Syntax, data types, OOP, decorators, generators, comprehensions, standard libraries (os, sys, pathlib, itertools).
PythonOOPStdlib
Week 02
Math for AI
Linear algebra (matrices, eigenvalues, SVD), calculus (derivatives, gradients, chain rule), NumPy for numerical ops.
NumPyLinearAlgebraCalculus
Week 03
Probability & Statistics
Probability distributions, Bayes' theorem, hypothesis testing, p-values, confidence intervals, information theory basics.
StatsBayesProbability
Week 04
Data Wrangling & EDA
Pandas, data cleaning, missing values, outliers, feature distributions, Matplotlib/Seaborn visualizations, storytelling with data.
PandasEDASeaborn
Month 02

Core Machine Learning

4 WEEKS
🤖
Goal: Master classic ML end-to-end — not just training models, but understanding why they work and when to use each one. Ship a real project.
Week 05
Supervised Learning
Linear & logistic regression, decision trees, evaluation metrics (precision, recall, F1, ROC-AUC), bias-variance tradeoff.
sklearnRegressionEvaluation
Week 06
Advanced Algorithms
SVMs, Random Forests, XGBoost/LightGBM, Gradient Boosting. Hyperparameter tuning with Optuna. Kaggle competition strategies.
XGBoostOptunaKaggle
Week 07
Unsupervised Learning & NLP Basics
K-Means, DBSCAN, PCA, t-SNE. Intro to NLP: tokenization, TF-IDF, word embeddings (Word2Vec, GloVe), text preprocessing pipelines.
ClusteringNLPEmbeddings
Week 08 — Project Week 🛠
End-to-End ML Pipeline
Build a complete project: data → EDA → feature engineering → model → evaluation → MLflow experiment tracking → deploy with FastAPI. Add to GitHub.
MLflowFastAPIGitHub
Month 03

Deep Learning

4 WEEKS
🧠
Goal: Understand neural networks from scratch — forward pass, backprop, gradient descent. Learn PyTorch deeply (not just copy-paste).
Week 09
Neural Networks from Scratch
Perceptron, backpropagation, activation functions (ReLU, GELU, sigmoid, tanh), loss functions, gradient descent variants.
BackpropActivationsGradients
Week 10
PyTorch Deep Dive
Tensors, autograd, custom datasets/dataloaders, training loops, optimizers (Adam, AdamW), LR schedulers, GPU/CUDA, mixed precision (AMP).
PyTorchCUDAAMP
Week 11
CNNs & Computer Vision
Convolutions, pooling, BatchNorm, ResNet/EfficientNet architectures, data augmentation (Albumentations), image classification project.
CNNResNetAlbumentations
Week 12
RNNs, LSTMs & Sequence Models
RNNs, LSTMs, GRUs, vanishing gradient problem. Text generation, time series forecasting. Intro to attention mechanism as motivation for Transformers.
LSTMAttentionSequences
Month 04

Advanced Deep Learning & Deployment

4 WEEKS
⚡
Goal: Move from notebooks to production. Learn the architectures that power modern AI and how to actually deploy them in the real world.
Week 13
Transformers Architecture
Self-attention, multi-head attention, positional encodings, encoder-decoder architecture. Implement a mini-GPT from scratch. Read "Attention Is All You Need."
AttentionTransformersGPT
Week 14
Transfer Learning & Fine-Tuning
HuggingFace ecosystem, BERT/GPT fine-tuning, LoRA/QLoRA for parameter-efficient training, domain adaptation, few-shot learning.
HuggingFaceLoRAPEFT
Week 15
Object Detection & Segmentation
YOLO (v8/v11), Faster R-CNN, SAM (Segment Anything Model), semantic & instance segmentation, IoU/mAP metrics.
YOLOSAMDetection
Week 16 — Project Week 🛠
Deploy a DL Model to Production
Docker + FastAPI → cloud deploy (Hugging Face Spaces, Railway, or GCP). CI/CD pipeline, model versioning, latency optimization with ONNX/TorchScript.
DockerONNXCI/CD
Month 05

Generative AI & LLM Engineering NEW

4 WEEKS
✨
Goal: Master the skills that are most in-demand right now — LLM APIs, RAG systems, agents, and AI product development. This is where you become hireable.
Week 17
LLM APIs & Prompt Engineering
OpenAI / Anthropic / Gemini APIs, prompt engineering (chain-of-thought, few-shot, system prompts), structured outputs, JSON mode, function calling.
OpenAIAnthropicPrompting
Week 18
Embeddings & Vector Databases
Semantic search, embedding models (OpenAI, Cohere, BGE), vector stores (Pinecone, Chroma, Weaviate, pgvector), similarity search at scale.
PineconeChromaDBEmbeddings
Week 19
RAG Systems
Build production RAG pipelines with LangChain/LlamaIndex. Chunking strategies, hybrid search, reranking (Cohere), evaluation with RAGAS, agentic RAG.
LangChainLlamaIndexRAGAS
Week 20
AI Agents & Orchestration
ReAct agents, tool use, multi-agent systems (CrewAI, AutoGen), memory architectures, LangGraph for stateful workflows, MCP protocol.
AgentsLangGraphCrewAI
Month 06

Portfolio, MLOps & Job Prep NEW

4 WEEKS
🎯
Goal: Ship 3 standout portfolio projects, master MLOps fundamentals, and execute a smart job search. You're not just job-ready — you're standout-ready.
Week 21 — Project Week 🛠
Capstone Project #1: AI Product
Build a full-stack AI product: LLM + RAG + agent backend + React/Next.js frontend. Deploy publicly. Write a technical blog post about it. Share on LinkedIn.
Full-StackNext.jsBlog
Week 22
MLOps & Model Monitoring
Weights & Biases, DVC for data versioning, model registries, A/B testing models, data drift detection (Evidently), basic Kubernetes/cloud infra.
W&BDVCEvidently
Week 23
Interview Prep
ML system design (ML design primer), coding (LeetCode ML-specific), behavioral STAR stories, mock interviews, salary negotiation, offer evaluation.
System DesignLeetCodeBehavioral
Week 24
Network, Apply & Launch
Optimized LinkedIn + GitHub, cold outreach templates, AI community (Papers With Code, Hugging Face Discord, X/Twitter), open source contribution, job applications.
LinkedInOpen SourceNetworking
🏁 You've Shipped. You're Hired.
